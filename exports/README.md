# Downloadbestanden

- genesys-webrtc-azure-export.zip bevat de Function App, Bicep, configuratievoorbeelden, Cloud Shell-scripts, tests, documentatie en GitHub-workflows.
- functionapp-source.zip bevat alleen de deploybare Functions-broncode. Gebruik remote build.

Lees na uitpakken START_HIER.md en azure-functions/VALIDATION.md. Vul de tenantconfiguratie in en start met dry-run.

Dit zijn exportmomentopnamen. Bouw na eigen wijzigingen opnieuw met azure-functions/scripts/build_export.py.
